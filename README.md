# WiProgram
Це програма написана на мові Python на основі PyQt5, яка покищо додає кругове меню, до якого можна додавати свої катеогії та у ці категорії можна додати певні дій:
відкривання файлів, папок, посилань, також там присутні макроси та POSS та GET запити до API.

При запуску програма створить файл `action.json`. Якщо його там немає! 
По-замовчуваню встановлена кнопки для відкриття кругового меню `~`, її можна змінити у вікні `Radial Menu Setting` у вкладці `File`
![Radial Menu Setting Shortcut]()

Дані зберігаються у форматі json у файлі `action.json` структура виглядає осьтак
``` json
{
    "category_name": {
        "actions": [
            {
                "name": "name"
                "type": "type"
                "data": "path, url, any"
            }
        ]
    }
}
```
